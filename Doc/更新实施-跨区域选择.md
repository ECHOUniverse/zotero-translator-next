# 更新实施文档:跨区域选择(多选拼段翻译)

> 版本：v1.1（v1.0 后经 grilling 会话修订：容器从独立区块改为 reader 区块内嵌）
> 日期：2026-08-13
> 状态：已实施（v0.5.1）
> 目标版本：v0.5.1
> 配套：[`PLAN.md`](./PLAN.md) 为总方案（本文档是独立的功能更新实施规格，不修改 PLAN.md）

---

## 1. 背景与需求

**问题**:PDF 文献中同一段落的内容往往不连续——双栏排版、页脚注、跨页、图注框都会把一段文字拆散。单次划选只能选中其中一块,翻译结果段落残缺。

**目标**:允许用户把多个不连续区域累积为一次翻译的原文,合成完整段落,走现有翻译管线。

**约束**:不改变既有单段翻译行为;默认状态零 UI 占用;基于官方公开事件,不侵入 pdf.js 内部。

## 2. 设计决策(已确认)

| # | 维度 | 决策 |

## 5. 数据模型

```ts
// src/modules/selection.ts(新增)
export interface SelectionRegion {
  /** 添加顺序号(展示序号,从 1 起) */
  seq: number;
  /** 页码(0 基,来自 annotation.position.pageIndex) */
  pageIndex: number;
  /** 页内文档序(来自 annotation.sortIndex) */
  sortIndex: number;
  /** 页签文案(来自 annotation.pageLabel,如 "p. 3") */
  pageLabel: string;
  /** 区域原文 */
  text: string;
  /** 去重键:pageIndex + sortIndex */
  key: string;
}

export class SelectionManager {
  private regions = new Map<number, SelectionRegion[]>();
  private listeners = new Set<() => void>();
  static readonly MAX_REGIONS = 50;

  /** 加入区域;已存在(同 key)返回 { added: false, reason: 'dup' };超上限返回 { added: false, reason: 'limit' } */
  add(itemID: number, region: Omit<SelectionRegion, 'seq' | 'key'>): { added: boolean; reason?: 'dup' | 'limit'; count: number };
  remove(itemID: number, key: string): void;
  clear(itemID: number): void;
  /** 按文档顺序返回排序后的副本 */
  get(itemID: number): SelectionRegion[];
  has(itemID: number): boolean;
  /** 区块订阅:add/remove/clear 后触发,区块据此激活/隐藏 + 重绘 */
  subscribe(listener: () => void): () => void;
}
```

排序比较器:`pageIndex` 升序 → `sortIndex` 升序(区域 `seq` 仅作展示,不参与排序)。

## 6. 技术方案

### 6.1 装配

`src/addon.ts`:新增 `selection: new SelectionManager()` 注入 `ReaderModule`(构造参数扩展)与 `registerSections`(新参数);`hooks.ts` 在 `reader.registerSelectionPopup()` 处同步传入。

### 6.2 弹层改造(`src/modules/reader.ts`)

`registerSelectionPopup()` 事件回调中,现有「翻译」按钮旁追加「加入选区」按钮:

```
流程:划选 → 弹层出现 [翻译] [加入选区] → 点「加入选区」:
  1. 若 autoDebounceTimer 挂起 → clearTimeout(取消划选即译)
  2. annotation 无 text → 直接 return(现有守卫已处理)
  3. selection.add(logicalItemID(reader.itemID), {
       pageIndex: annotation.position?.pageIndex ?? 0,
       sortIndex: annotation.sortIndex ?? 0,
       pageLabel: annotation.pageLabel ?? `p. ${pageIndex + 1}`,
       text: annotation.text,
     })
  4. 按钮反馈:
     - added  → 文案「✓ 已加入(N段)」,800ms 后恢复「加入选区」
     - dup    → 文案「已在选区中」,800ms 后恢复
     - limit  → 文案「已达上限(50段)」,800ms 后恢复
  5. 弹层保持(不改变选区),用户继续划下一段
```

细节:
- 按钮间 `gap: 4px` 与现有容器样式一致
- 无 `position`/`sortIndex` 字段时(极端兼容):`pageIndex=0`、`sortIndex=seq`(退化为按添加顺序排序,仅作兜底)
- 导出 `getCurrentReader()`(改为 public/导出),供区块跳页复用

### 6.3 容器与渲染（v1.1：reader 区块内嵌，无独立区块）

**不注册独立区块**（撤销 v1.0 的 `translator-selection`，避免第三个 sidenav 图标与底部位置）。选区块内嵌于 reader 区块骨架，位于工具栏与「当前翻译」之间：

```html
<!-- readerBodyXHTML() -->
<div class="ztr-toolbar" id="ztr-reader-toolbar"></div>
<div class="ztr-selection" id="ztr-reader-selection" hidden></div>
<div class="ztr-section-title-row" id="ztr-reader-current-title"></div>
```

**激活/隐藏时机**（`updateSelectionBlock(ctx)`，选区订阅 / `onItemChange` / `onRender` 共用）：
- 激活条件：`ctx.itemID != null && selection.has(itemID) && tabType === 'reader'` → `block.hidden = false` + 重绘；否则 `hidden = true`（零占用）
- reader 区块 `onInit` 订阅 `SelectionManager`（add/remove/clear 后刷新）
- 无选区 / 非阅读器 tab / 无条目 → 整块隐藏，无空态页面

**卡片结构**（`buildSelectionCard` 幂等 + `renderSelectionList` 列表刷新）：
- 标题行：`ztr-section-selection-title`（跨区域选区）+ 段数徽章 `ztr-selection-count`（如「3 段」）
- 区域行：`① p.3 头尾摘要(头尾各 24 字符，…连接，全文在 title) ×(删除)`；行点击 → `Zotero.Reader.getByTabID(win.Zotero_Tabs.selectedID)?.navigate({ pageIndex })`
- 动作行：「翻译全部」（`ztr-btn-primary` 主色实心）/「清空」（`ztr-btn-danger` 危险色），行尾确认后 `selection.clear`
- 列表项数量 ≥ 2 时行首显示文档顺序序号（`①②③…`，按排序后位置）
- 「翻译全部」：拼接（§6.5）→ `translateManager.translate({ sourceText: joined, itemID, channelId: getSelectedChannelId() })` → 结果自然出现在现有「当前翻译」卡片（同一 `subscribe` 驱动），无需额外改动

**汉化（v1.1 修复）**：`ztr-selection-*` 与 `ztr-add-to-selection` 等字符串原误放 `mainWindow.ftl`，而 `getString()` 只加载 `addon.ftl`，导致按钮/弹层回退显示原始命令 ID。已全部移入 `addon.ftl`（zh-CN + en-US），`mainWindow.ftl` 仅保留区块 header 字符串。

### 6.4 生命周期与边界

- 内存级 Map,关闭 Zotero 自然清空;切换文献不丢
- 上限 50:add 拒绝 + 按钮提示(§6.2 step 4)
- 空选区 → 区块隐藏,无空态页面(激活瞬间即有内容)
- 区块渲染时对 `ctx.itemID == null` 一律隐藏(与现有「绝不回退全局」原则一致)

### 6.5 拼接(`translateAll`)

```ts
function joinRegions(regions: SelectionRegion[]): string {
  const sorted = [...regions].sort((a, b) =>
    a.pageIndex - b.pageIndex || a.sortIndex - b.sortIndex);
  let out = '';
  for (const r of sorted) {
    const t = r.text.trim();
    if (!t) continue;
    if (!out) { out = t; continue; }
    // 区域边界连字符修复:前段以 "-" 结尾且后段以字母开头 → 直接相连
    if (/[A-Za-z]-$/.test(out) && /^[a-z]/.test(t)) {
      out = out.slice(0, -1) + t;
    } else {
      out += ' ' + t;
    }
  }
  return out;
}
```

- 拼接结果作为 `sourceText` 送入现有管线;格式化(断行合并/连字符修复)继续作用于合成文本
- 记一条历史(现有落库逻辑,无需改动)

## 9. 风险与对策
