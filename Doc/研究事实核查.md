# Research: Zotero 7 翻译插件（类 zotero-pdf-translate）规划所需事实核查

> 研究日期基准：2026 年 7 月（依据搜索到的最新事实：Zotero 9.0.6 于 2026-07-07 发布、zotero-pdf-translate PR 合并至 2026-05、bing-translate-api 4.2.1 发布）。
> 所有事实均给出主来源 URL。API 标识符与代码保持原文，说明文字用中文。

## Summary

Zotero 7 的官方插件 API 中**不存在 `reader.registerSidebarTab`**；读者右侧栏即 item pane，插件通过 `Zotero.ItemPaneManager.registerSection()` 注册侧栏区块（zotero-pdf-translate 正是这么做的），向 reader UI 注入 DOM 用 `Zotero.Reader.registerEventListener()`。选中文本通过 `"renderTextSelectionPopup"` 事件的 `params.annotation.text` 获取。当前版本格局已进入快速发布周期：Zotero 8.0 于 2026-01-22 发布，Zotero 9.0 于 2026-04-10 发布（当前稳定版 9.0.6，2026-07-07），因此插件应面向 7.x/8.x/9.x 三兼容（`strict_min_version: "6.999"`，`strict_max_version` 按测试版本声明）。免费翻译方面：`api-edge.cognitive.microsofttranslator.com` 是微软**未官方文档化**的内部端点（zotero-pdf-translate 目前用 `edge.microsoft.com/translate/auth` 取 Bearer token 调用它），`bing-translate-api` npm 包已重写（v4.2.x，不再依赖 api-edge，改用 `bing.com/ttranslatev3` 抓取 + 官方 Azure v3 的 MET 模块）；Azure Translator 官方有 F0 免费层（2M 字符/月，需订阅密钥）。

## Findings

### 1. Reader 侧栏 Tab 注册 API（`registerSidebarTab` 是否存在）

1. **Zotero 7/8/9 没有 `reader.registerSidebarTab` 这个原生 API。** 直接检索 Zotero `main` 分支源码 `chrome/content/zotero/xpcom/reader.js`，仅找到 `registerEventListener(type, handler, pluginID)` / `unregisterEventListener`，无任何 "registerSidebar" 匹配。官方文档同样只列出自定义 Reader 事件处理器。[Zotero 7 for Developers](https://www.zotero.org/support/dev/zotero_7_for_developers) · [reader.js 源码](https://github.com/zotero/zotero/blob/main/chrome/content/zotero/xpcom/reader.js)
2. **官方签名**（来自 reader.js 源码 JSDoc）：`Zotero.Reader.registerEventListener(type, handler, pluginID = undefined)`。`ReaderEventType` 共 8 种：`"renderTextSelectionPopup" | "renderSidebarAnnotationHeader" | "renderToolbar" | "createColorContextMenu" | "createViewContextMenu" | "createAnnotationContextMenu" | "createThumbnailContextMenu" | "createSelectorContextMenu"`。处理器收到 `{ reader, doc, params, append }`。插件禁用/卸载时自动移除，手动移除用 `unregisterEventListener(type, handler)`。官方示例（向选区弹窗注入译文容器）：
   ```js
   Zotero.Reader.registerEventListener('renderTextSelectionPopup', (event) => {
     let { reader, doc, params, append } = event;
     let container = doc.createElement('div');
     append(container);
     setTimeout(() => container.replaceChildren('Translated: ' + params.annotation.text), 1000);
   }, 'make-it-red@zotero.org');
   ```
   [Zotero 7 for Developers](https://www.zotero.org/support/dev/zotero_7_for_developers)
3. **"读者右侧栏 Tab"的正确官方做法是 `Zotero.ItemPaneManager.registerSection()`** —— Zotero 7 中 reader 的右侧栏就是 item pane（垂直区块 + sidenav）。zotero-pdf-translate 用 `paneID: "translate"` 注册自己的侧栏面板（含 `sectionButtons`、`bodyXHTML: "<translator-plugin-panel />"`、`onRender/onItemChange/onInit/onDestroy` 钩子），见其 [src/modules/tabpanel.ts](https://github.com/windingwind/zotero-pdf-translate/blob/master/src/modules/tabpanel.ts)。
4. 另有一个社区工具库方案：zotero-plugin-toolkit 的 `ReaderTabPanelManager.register(tabLabel, renderPanelHook: (panel: XUL.TabPanel, ownerDeck: XUL.Deck, ownerWindow: Window, readerInstance) => void, options)` —— "Register new `<tabpanel>` in reader right-side bar"（这是注入原生 tabbox 的旧式手段，Zotero 7 下已非首选）。[toolkit API 文档 (unpkg 2.3.37)](https://app.unpkg.com/zotero-plugin-toolkit@2.3.37/files/docs/zotero-plugin-toolkit.readertabpanelmanager.register.md)

### 2. 获取 PDF viewer 当前选中文本

1. **官方事件方式（zotero-pdf-translate 实际用法）**：监听 `"renderTextSelectionPopup"`，选中文本在 `params.annotation.text`。其 [src/modules/reader.ts](https://github.com/windingwind/zotero-pdf-translate/blob/master/src/modules/reader.ts)：
   ```ts
   Zotero.Reader.registerEventListener("renderTextSelectionPopup", (event) => {
     const { reader, doc, params, append } = event;
     addon.data.translate.selectedText = params.annotation.text.trim();
     addon.hooks.onReaderPopupShow(event);
   }, config.addonID);
   ```
2. **程序化方式（toolkit `ReaderTool`）**：`reader._internalReader._lastView._selectionPopup?.annotation`（`getSelectedAnnotationData`），`getSelectedText(reader): string` 返回其 `.text`。当前 reader 实例用 `Zotero.Reader.getByTabID(Zotero_Tabs.selectedID)` 获取（`Zotero_Tabs.selectedType === "reader"` 时），并 `await reader._initPromise`。[zotero-plugin-toolkit src/tools/reader.ts](https://github.com/windingwind/zotero-plugin-toolkit/blob/master/src/tools/reader.ts)
3. **直接访问 pdf.js**：reader 运行在 iframe 中，入口是 `reader._iframeWindow`（或 `reader._primaryView._iframeWindow`）。社区验证过的取整页文本方式：`Zotero.Reader.getByTabID(Zotero_Tabs.selectedID)._primaryView._iframeWindow.PDFViewer.getPage(1).then(pdfPage => pdfPage.getTextContent()...)`。注意这些是内部属性，跨版本可能变动。[zotero-dev 邮件组讨论](https://groups.google.com/g/zotero-dev/c/lj_thX_5P2Y)

### 3. Item pane 插件区块（`Zotero.ItemPane` / `registerPluginTab` 是否存在）

1. **不存在 `Zotero.ItemPane` 全局对象，也没有 `registerPluginTab` API。** Zotero 7 官方 API 是 `Zotero.ItemPaneManager`，含 5 个方法（已核对 `main` 分支源码 [pluginAPI/itemPaneManager.js](https://github.com/zotero/zotero/blob/main/chrome/content/zotero/xpcom/pluginAPI/itemPaneManager.js)）：
   - `registerSection(options) ⇒ string|false`（必填 `paneID`、`pluginID`、`header{l10nID,icon}`、`sidenav{l10nID,icon,orderable?}`；可选 `bodyXHTML`、`onInit`、`onDestroy`、`onItemChange`、`onRender`、`onAsyncRender`、`onToggle`、`sectionButtons[{type,icon,onClick}]`）
   - `unregisterSection(paneID)`、`registerInfoRow(options)`、`unregisterInfoRow(rowID)`、`refreshInfoRow(rowID)`
   - 内置 paneID 冲突检查（info/abstract/attachments/notes/tags…）；`paneID` 会以 pluginID 命名空间化；插件禁用时自动注销。官方示例见 [Zotero 7 for Developers](https://www.zotero.org/support/dev/zotero_7_for_developers)（"Custom Item Pane Sections"）。
2. **开发中的新 API**：`Zotero.ItemPaneManager.registerView({id, pluginID, label, mode, onReady, ...})` 在 [zotero/zotero issue #3380](https://github.com/zotero/zotero/issues/3380) 提出（item pane 视图级 API），截至本次核查**未合入 main**，不可依赖。

### 4. Bing 免费翻译端点与 bing-translate-api 状态

1. **`api-edge.cognitive.microsofttranslator.com` 是微软内部/未文档化端点**：Microsoft 官方文档只覆盖 `api.cognitive.microsofttranslator.com`（或区域端点）+ `Ocp-Apim-Subscription-Key` / Entra bearer token 认证。[官方认证文档](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/reference/authentication)
2. **zotero-pdf-translate 当前 Bing 实现**（[src/modules/services/bing.ts](https://github.com/windingwind/zotero-pdf-translate/blob/master/src/modules/services/bing.ts)）：`POST https://api-edge.cognitive.microsofttranslator.com/translate?from=..&to=..&api-version=3.0&includeSentenceLength=true`，认证头是 `authorization: Bearer <token>`，token 来自 `GET https://edge.microsoft.com/translate/auth`（Edge 浏览器翻译器的匿名 token 端点，缓存 5 分钟）。**并没有用 `Authorization: EdgeBing` 头** —— 那是更早期的社区手法（旧版 bing-translate-api 及各种 Python 脚本）。这类非官方流仍偶发可用，但无 SLA：会 401/429/验证码，随时可能失效。
3. **`bing-translate-api` npm 包现状**：v4.2.1 为最新（v4.2.0 发布于 2025-11-24），MIT，周下载约 38.6K，33 个依赖方，作者仍在维护（"modestly maintained"，0 open issues），自动测试 CI 在跑。[npm 页面](https://www.npmjs.com/package/bing-translate-api) · [Releases](https://github.com/plainheart/bing-translate-api/releases)。**当前实现已不依赖 api-edge**：
   - 抓取 `https://{s}bing.com/ttranslatev3?isVertical=1&IG=..&IID=..`（referer 指向 bing.com/translator，IG/IID/key/token 从 translator 页刮取），v3.0.0 起有 EPT 模式（`&ref=TThis&edgepdftranslator=1&SFX=`）降低限流；[src/index.js](https://github.com/plainheart/bing-translate-api/blob/master/src/index.js)
   - v4.0.0 起新增 **MET 模块**：直接用**官方 Azure Translator v3 REST API**（`learn.microsoft.com/azure/ai-services/translator/reference/v3-0-translate`），默认匿名免费授权，也可传私有密钥（`Ocp-Apim-Subscription-Key` 或 JWT `Authorization`）。[src/met/README.md](https://github.com/plainheart/bing-translate-api/blob/master/src/met/README.md)
4. **Azure Translator 免费层存在**：F0 层 **2M 字符/月免费**（标准翻译 + 自定义翻译训练），需 Azure 账号 + 资源密钥；单请求上限 50,000 字符。[Azure Translator 定价页](https://azure.microsoft.com/en-us/pricing/details/translator/) · [Service limits](https://learn.microsoft.com/en-us/azure/ai-services/translator/service-limits)

### 6. zotero-pdf-translate 架构

1. **翻译历史/队列是纯内存**：`addon.data.translate.queue`（`TranslateTask[]`，`maximumQueueLength: 100`），见 [src/addon.ts](https://github.com/windingwind/zotero-pdf-translate/blob/master/src/addon.ts) 与 [src/utils/task.ts](https://github.com/windingwind/zotero-pdf-translate/blob/master/src/utils/task.ts)。**没有自定义 SQLite 表、没有 Zotero.DataAccessObject**。缓存 = 在同一内存队列里查找同 raw+service+lang 的成功任务。持久化只落在 Zotero 自身数据上：
   - 批注译文 → 写入 annotation 的 comment 或 body（pref `annotationTranslationPosition`）
   - 标题/摘要译文 → 经 `ztoolkit.ExtraField` 写入条目 Extra 字段（key `titleTranslation`/`abstractTranslation`）
   - 密钥/配置 → `Zotero.Prefs`（服务密钥存在 `secretObj` JSON pref；Bing token 存 `bingToken` JSON pref）
2. **provider/translator 抽象**：`src/modules/services/base.ts` 定义 `TranslateService`（字段：`id`、`type: "sentence"|"word"`、`name`、`defaultSecret?`、`secretValidator?`、`config?`、`requireExternalConfig?`、`translate(data: TranslateTask)`）；`TranslationServices` 注册表类提供 `getServiceById` / `getAllServices` / `getAllServicesWithType` / `runTranslationTask` / `sortServices`（免费免密钥优先排序）。任务经 `TranslateTaskRunner.run()` 执行（自动语言检测、注入 secret、状态机 waiting→processing→success/fail、失败可回退候选服务、日志脱敏）。新增服务 = 复制 [src/modules/services/_template.ts](https://github.com/windingwind/zotero-pdf-translate) 填字段即可。[src/modules/services/index.ts](https://github.com/windingwind/zotero-pdf-translate/blob/master/src/modules/services/index.ts)
3. **内置引擎共 45 个**：Aliyun、Baidu(+Field)、Bing、BingDict、Caiyun、CambridgeDict、Claude、Cnki、CollinsDict、DeepL Free/Pro/Custom、DeepLX、FreeDictionaryAPI、Gemini、Google、GoogleAPI、ChatGPT、customGPT1-3、azureGPT、Haici(+Dict)、Huoshan(+Web)、Iciba、LibreTranslate、Microsoft、Mtranserver、Niutrans、Nllb、Openl、Pot、QwenMT、Tencent(+Transmart)、WeblioDict、XFfrans、Youdao(+Dict/Zhiyun/ZhiyunLLM)、GramotaDict。（同一文件 [services/index.ts](https://github.com/windingwind/zotero-pdf-translate/blob/master/src/modules/services/index.ts) 的 import/register 列表。）

### 7. Zotero 8 破坏性变更与插件指导

1. **Zotero 8.0 于 2026-01-22 发布**（官方博客），核心是 Mozilla 平台升级 Firefox 115→140（早期 "7.1" beta 是 128）。[Zotero 8 博客](https://www.zotero.org/blog/zotero-8/) · [Zotero 8 for Developers](https://www.zotero.org/support/dev/zotero_8_for_developers)
2. **官方列出的破坏性变更**（Zotero 8 for Developers）：所有 JSM → ESM（提供 `migrate-fx140/migrate.py esmify` 迁移脚本）；Bluebird 移除（提供 `asyncify` 脚本；`Zotero.Promise.delay/defer` 保留但 `defer` 不能当构造器用；`Zotero.spawn()` 已删）；手动 `Services.jsm` import 需移除；`nsIScriptableUnicodeConverter`、`nsIOSFileConstantsService`、`nsIDOMChromeWindow` 移除；`Services.appShell.hiddenDOMWindow` 仅 macOS 可用；`ZOTERO_CONFIG` 需显式 import；**preference pane 脚本运行在各自独立 global scope**（跨 pane 共享变量须显式挂 `window`）；按钮 label 用 property 而非 attribute；`zotero:` URI 首段解析为 host。
3. **插件兼容要求**：官方公告——插件须测试后把 `strict_max_version` 更新为 `"8.0.*"`（manifest 仍是 WebExtension 风格 `manifest_version: 2` + `applications.zotero`，无 manifest 大版本变化）。[zotero-dev 公告](https://groups.google.com/g/zotero-dev/c/uQhEGkJEzYs) · [Zotero 7 for Developers（manifest 示例）](https://www.zotero.org/support/dev/zotero_7_for_developers)
4. **新 API**：`Zotero.MenuManager.registerMenu({menuID, pluginID, target, menus:[...]})`（target 覆盖主窗口/reader 菜单栏、条目右键、item pane 行、sidenav 等）。[Zotero 8 for Developers](https://www.zotero.org/support/dev/zotero_8_for_developers)
5. **OS 支持变化**：Zotero 8 起不再支持 macOS ≤10.14、Windows 7/8。[8.0 changelog](https://www.zotero.org/support/8.0_changelog)

### 8. 插件偏好设置（Zotero.Prefs）与自定义偏好面板

1. **`Zotero.Prefs` API**：`get(key, global)`、`set(key, value, global)`、`clear(key, global)`、`registerObserver(key, cb, global)` / `unregisterObserver(id)`。插件键通常带前缀（如 `extensions.zotero.addontemplate.*`）；Zotero 7 起默认值放插件根目录的 `prefs.js`（安装/启用/每次启动时读取）。值存于 Zotero 数据目录的 `prefs.js`，**不同步**。zotero-pdf-translate 的封装见 [src/utils/prefs.ts](https://github.com/windingwind/zotero-pdf-translate/blob/master/src/utils/prefs.ts)。[Preferences | Dev Docs](https://windingwind.github.io/doc-for-zotero-plugin-dev/main/preferences) · [Zotero 7 for Developers（Default Preferences）](https://www.zotero.org/support/dev/zotero_7_for_developers)
2. **API 密钥存储**：可以普通字符串 pref 或 JSON 字符串 pref（zotero-pdf-translate 把全部服务密钥存 `secretObj` JSON，读取时 `JSON.parse(getPref("secretObj"))`，`setServiceSecret` 更新）。明文存 prefs.js（无加密；Zotero 也没有为插件提供加密存储 API）。
3. **自定义偏好面板：支持，官方 API 是 `Zotero.PreferencePanes.register({pluginID, src, scripts, stylesheets, helpURL, image})`**（Zotero 7 起内置；实现见 [xpcom/preferencePanes.js](https://github.com/zotero/zotero/blob/main/chrome/content/zotero/xpcom/preferencePanes.js)）。`src` 是 XUL/XHTML 片段（不能有 `<!DOCTYPE>`，默认 XUL 命名空间，HTML 元素用 `html:` 前缀）；Zotero 7 起 `<preference>` 标签改为字段直接绑定 `preference="extensions.zotero.xxx.key"`，脚本里直接 `Zotero.Prefs.get()`；Fluent 通过 `<linkset><html:link rel="localization" href="..."/></linkset>` 引入；插件卸载自动注销。官方示例见 [Zotero 7 for Developers（Preference Panes）](https://www.zotero.org/support/dev/zotero_7_for_developers)。注意 Zotero 8 中 pane 脚本是独立 global scope。

### 9. 当前 Zotero 版本号

1. **Zotero 7.x 最新稳定**：**7.0.32**（2026-01-14），此后 7.0 分支无更新。[7.0 changelog](https://www.zotero.org/support/7.0_changelog)
2. **Zotero 8**：**8.0 已发布**（2026-01-22），不再是 beta。[Zotero 8 博客](https://www.zotero.org/blog/zotero-8/)
3. **Zotero 9（当前稳定）**：**9.0 于 2026-04-10 发布，当前 9.0.6（2026-07-07）**。Zotero 已宣布更快发布周期（新 major 约每 6–8 个月），当前 10.0 开发分支已存在（main 已是 11.0.SOURCE）。[Zotero 9 博客](https://www.zotero.org/blog/zotero-9/) · [changelog](https://www.zotero.org/support/changelog) · [论坛讨论（发布节奏）](https://forums.zotero.org/discussion/133127/frequent-major-version-changes-and-the-current-plugin-compatibility-model)
4. **对插件规划的含义**：以 Zotero 7.0 为兼容底线（`strict_min_version: "6.999"`），优先在 8.x/9.x 上测试；新插件建议直接声明 `strict_max_version` 为当前测试到的版本（如 `"9.0.*"`），并通过 update manifest 滚动放行。
